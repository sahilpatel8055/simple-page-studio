## 9. LPU MCA Curriculum – Semester-Wise Structure

The supplied curriculum is organised across four semesters.

| Semester | Subjects |
|---|---|
| Semester I | Programming Fundamentals, Database Management Systems, Computer Organization, Operating Systems, Software Engineering |
| Semester II | Data Structures, Computer Networks, Web Technologies, Object-Oriented Programming, Design and Analysis of Algorithms |
| Semester III | Cloud Computing, Artificial Intelligence, Data Analytics, Mobile Application Development, Machine Learning |
| Semester IV | Major Project, Cyber Security, Emerging Technologies, Software Testing, Industry-Oriented Electives |

### Semester I – Building the foundation

The first semester establishes core computing knowledge. Programming, databases, operating systems and software engineering provide the base needed for later technical subjects.

### Semester II – Programming and systems

Students progress into data structures, algorithms, networking, web technologies and object-oriented programming. These areas strengthen problem-solving and application-development knowledge.

### Semester III – Advanced technology

Cloud computing, AI, data analytics, mobile applications and machine learning introduce modern technology domains.

### Semester IV – Application and project work

The final semester focuses on a major project, cybersecurity, emerging technologies, software testing and industry-oriented electives.
